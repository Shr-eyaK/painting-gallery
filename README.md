## Painting Gallery

A web application for displaying and managing a digital gallery of paintings using PHP and MySQL.

![Painting Gallery Screenshot](painting-gallery.png)

## Features

- View paintings in a gallery layout
- Add new painting entries
- Delete existing paintings
- Database-backed storage using MySQL
- Responsive interface built with HTML and CSS
- Homepage redirect to gallery view

## Project Structure

```text
Schema.sql
addPainting.php
deletePainting.php
index.php
main.css
painting-gallery.png
paintings.php
showPaintings.php
```

## Tech Stack

- PHP
- MySQL
- HTML
- CSS
- Git & GitHub

## Running the App

- Clone the repository
- Import `Schema.sql` into MySQL
- Configure database connection settings if needed
- Run using XAMPP or another PHP server environment
